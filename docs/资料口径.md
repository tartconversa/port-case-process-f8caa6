# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

consignment为委托，declaration为申报，sample为实收样品，case为独立服务事项。必需事项全部finish且无rejected才算办结；released_at后解除必需但不删除工作量，withdrawn不等于办结。时间precision=day只表示本地日期24小时内的未知时点，不能填零点；不能唯一判断时用范围和待核解释。transfer表示新机构已接管，旧机构后报finish只结束原机构工作不结束新责任。pause原因applicant由企业承担，agency仍归机构，resume结束暂停。委托总经过按并行区间并集，机构工作时长按各自calendar开窗；未列日期为非工作日。后续文件later_receipts独立接收。

## consignments
中心委托。

记录键：['consignment_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| consignment_id | string | 委托 |
| enterprise | string | 企业 |
| business_type | string | 业务 |
| received | datetime | 受理 |

## later_receipts

记录键：['event_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| event_id | string | 回执 |
| case_id | string | 事项 |
| action | string | 动作 |

| value | string | 时点 |
| precision | string | 精度 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。
